# 残障人生指南

讲残疾之后怎么防病、怎么少受罪，出了意外怎么救。讲哪些钱本来就有你一份、去哪里领，哪些证件和卡借出去会把自己搭进去。也讲怎么上学找工作、上班受了伤怎么认定和拿钱、恋爱结婚生孩子要注意什么、出门和出国怎么走。<br>
60 条建议，每条写明花掉什么、换回什么、证据有多硬，来源只引期刊论文和官方文件。

不用全做：这是按性价比排好的备选单，不是任务清单。挑走一两条就算数。所有条目写给残疾人本人，涉及照护和代办的部分单独写给家属。

## 怎么读

- **不用全做**：这是一份按性价比排好的备选单，不是任务清单。每节内的条目按性价比从高到低排，从每节前几条开始看就行。
- **想让 AI 帮你查**：仓库里带了一个中文 skill（[skills/canzhangrenshengzhinan-guide](skills/canzhangrenshengzhinan-guide/)），Claude Code 和 Codex 都能装。装上以后直接问「残疾人证能领什么」「工伤认定期限过了怎么办」，它会先把相关条目查出来，再按书里的方式回答，并注明出自第几节第几条。查不到就说查不到，不自己编数字。
- **想按条件挑**：打开[在线检索页](https://sddzlsc.github.io/canzhangrenshengzhinan/)，可以按关键词、章节、证据等级筛，也可以按「花不花钱、花多少时间、要不要毅力」这三样筛，几个条件能叠着用。页面上的内容直接取自行文，正文一改，页面跟着改。
- **想核对数字**：每条都有「来源」栏，只放期刊论文（附 DOI 或 PubMed 链接）和官方文件。每条来源当时打开过没有、用了原文哪一句，都记在 [docs/核实记录/](docs/核实记录/) 里；打不开的、没有采用的来源也记在里面，不装作没有。
- **只想看结论最硬的**：在检索页里勾选证据等级 A，只留下有具体数字、能逐字核对条文的条目——有具体数字、来自随机试验和大型试验的 45 条。
- **只想看最省力的**：勾选性价比「极高」，得到 6 条既不花钱、又不怎么花时间、收益又大的条目。
- **嫌字多**：每条的第一行「成本」和第二行「说人话」加起来一百多字，看完这两行就够拿主意；「收益」栏原样留着全部数字和出处，想自己核对再看。

每条建议长这样：

```markdown
### 1. 戒烟，去戒烟门诊开戒烟药，别只靠硬扛
- 成本：戒烟药一个月几十元到几百元……
- 说人话：一直抽烟的人，平均少活十年以上……
- 收益：美国一项跟踪 20 万人的研究……（HR 3.0，99% CI 2.7–3.3）……
- 证据等级：A
- 来源：Jha P 等 (2013). …… The New England Journal of Medicine. <https://doi.org/10.1056/NEJMsa1211128>
- 备注：……
```

## 四种资源

全书按性价比算账，换回的东西分四样，**四样之间不换算**：「少死几个人」和「每年省几百元」不在一把尺子上。

| 口径 | 换回什么 | 这一版的重点 |
| --- | --- | --- |
| 寿命（死亡率） | 总死亡率、特定死因、健康结局 | 第 1、2、3、8、9 节 |
| 金钱 | 现金、待遇、能省的费用 | 第 4、6、7 节 |
| 时间与精力 | 省下来的时间和体力 | 第 2、5、9、10 节 |
| 人身自由 | 避免刑责、拘留、非法收治 | 第 4、5、8、10 节 |

## 证据分级

每条建议都标注证据等级：

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查（来自随机分组的试验、多项研究合并的分析、跟踪很多人很多年的大型队列），或者引用的是能逐字核对的法律法规条文、国家标准 |
| B | 有研究或官方文件支持，但给不出确切数字；或者只有小样本、单一研究；政策和流程类的官方说法也放在这一级 |
| C | 通行做法或者作者判断，没有直接的研究文献支撑，必须在备注里写明依据 |

全书 60 条中 A 级 45 条、B 级 15 条、C 级 0 条，另有 4 条标注了争议、0 处标注了待核实。有争议的 A/B 级条目会标注「争议」并列出反方证据。所有来源只引原始文献（期刊论文附 DOI 或 PubMed 链接，或官方文件与官方网站），不引任何二手转述。不确定的数字宁可写「没找到」也不写。

## 性价比档

证据等级只回答「这个数字可不可信」，不回答「这件事值不值得做」。所以每条还另外标了两样：收益量级（好处有多大）和口径（换回的是哪一类东西）。检索页拿这两样加上三项成本，合出一个性价比档：

| 维度 | 取值 | 怎么定的 |
| --- | --- | --- |
| 口径 | 换寿命 / 换钱 / 换时间精力 / 换人身自由 | 看这条主要换回什么。不同口径之间不做比较 |
| 收益量级 | 大 / 中 / 小 | 尽量照着条目自己的「收益」栏机械套：换寿命看相对降幅（≥20% 为大，10–20% 为中，<10% 或只有中间指标的为小）；换钱看金额（万元级为大，数百到数千为中，几十元为小）；换人身自由看后果（避免刑责为大，避免拘留或行政处罚为中，避免民事纠纷为小）；换时间看省下多少（每天小时级为大，每周小时级为中，一次性为小）。数字不足以判定时才用判断，并在备注里写明 |
| 性价比 | 极高 / 高 / 一般 | 好处大、三项成本又都是零 = 极高；好处大、成本不高，或者好处中等、成本为零 = 高；剩下的 = 一般 |

全书 60 条中性价比极高 6 条（10%）、高 21 条（35%）、一般 33 条（55%）。

**这一档是作者的判断，不是证据**，按本书的标准它本身只算 C 级；它和证据等级是两回事。「一般」不等于不该做——全书的条目都是建议做的，只是这一档得自己掂量那笔花销值不值。

## 读懂数字（术语表）

正文尽量用日常说法，但引用研究的时候免不了出现几个统计名词。看不懂就查这张表；在线检索页里，把鼠标停在带虚线的词上（手机上点一下）也会弹出解释。

| 术语 | 说人话的解释 |
| --- | --- |
| 95% CI | 可信范围：同一个问题如果重做很多次，结果有 95% 的概率落在这一段里。范围越窄，结论越稳 |
| HR | 风险比：两组人比出来的死亡或发病风险倍数，1.00 表示一样，2.00 表示高一倍 |
| RR | 风险比的一种，多用在「吃药组和不吃药组比」这种两两比较上，读法和 HR 一样 |
| OR | 比值比：另一种两两比较的数字，少见病的时候和 RR 差不多，读法也差不多 |
| RCT | 随机对照试验：把人随机分成两组做对比，是判断「有没有效」最可靠的一类研究 |
| 队列研究 | 跟踪一群人很多年，看谁生病谁没生病。能看出相关性，不能证明因果 |
| 荟萃分析 | 把很多研究的数据合起来重算一遍，结论通常比单项研究稳 |
| 证据等级 | 本书自定的 A/B/C 三级，只说明数字可不可信，和值不值得做无关 |
| 性价比 | 成本（钱、时间、毅力）和收益量级合出来的三档：极高、高、一般 |
| 残疾人证 | 认定残疾类别和等级的凭证，分视力、听力、言语、肢体、智力、精神、多重七类，每类分一至四级 |
| 两项补贴 | 困难残疾人生活补贴和重度残疾人护理补贴，两笔独立的钱，标准由各省定 |
| 按比例就业 | 用人单位安排残疾人就业不得低于职工总数的 1.5%，达不到要缴残疾人就业保障金 |
| 残保金 | 残疾人就业保障金，用人单位没达到按比例就业要求时缴纳的政府性基金 |
| 长期护理保险 | 给失能人员的第六险，支付护理服务费用，起步阶段保障重度失能人员 |
| 辅助器具 | 轮椅、助听器、助视器、假肢这类补偿功能的器具，基本型配置有补贴 |
| 合理便利 | 为了让你能正常工作学习而做的调整，比如无障碍工位、读屏软件、调整班次、手语翻译 |
| 自主神经反射异常 | 脊髓损伤的人因为憋尿、便秘、皮肤受压等诱发的血压骤升，表现为剧烈头痛、出汗 |
| 神经源性膀胱 | 神经损伤导致的排尿功能障碍，常用定时导尿加药物管理 |
| 压疮 | 长期受压导致的皮肤和皮下组织损伤，俗称褥疮，坐轮椅和卧床的人高发 |
| 人身安全保护令 | 法院发的命令，禁止施暴者骚扰、跟踪、接触，也可以要求其迁出住所 |
